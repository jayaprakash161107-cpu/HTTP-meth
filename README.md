# MockAPI User Management Project

This is a simple JavaScript project that works with MockAPI.

I used the Fetch API to get and send user data.

## Features

- Get all users
- Get a single user by ID
- Add a new user
- Convert API response into JSON
- Send JavaScript object as JSON data
- Practice reusable API functions

## Technologies Used

- JavaScript
- Fetch API
- Async / Await
- MockAPI
- JSON
